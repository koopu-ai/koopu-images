# Security policy

Please report suspected vulnerabilities through this repository's private
GitHub Security Advisory form. Do not disclose exploitable details in a public
issue.

Only the exact image tags listed in the current README are maintained. An image
is supported only when its tag resolves to the OCI index digest recorded in the
private Koopu dependency baseline.

Reports should include the image reference, platform, reproduction steps, and
the observed versus expected behavior. Never include production credentials,
private keys, access tokens, database dumps, or customer data.
